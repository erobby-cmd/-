# marhav-eilat

## מה יש פה

| מקום | מה זה |
|---|---|
| `index.html` | היומן של אילת. הקובץ הראשי. |
| `editor-panel.js` | פאנל עורך ה AI. היומן טוען אותו. |
| `yoman/` | יומן פרוייקטים, הגרסה הכללית שפוצלה מהיומן של אילת. ראה `yoman/SYNC.md`. |
| `subs/` | כתוביות של ימי הצילום (`day01.srt` עד `day09.srt`). היומן קורא אותן מכאן. |
| `data/scenes/` | פירוק סצנות לכל יום צילום (`dayNN-brk.json`). קבצי ייבוא, הקוד לא טוען אותם לבד. |
| `data/frames/` | תמונות ממוזערות לכל יום (`dayNN-imgs.json`). קבצי ייבוא, הקוד לא טוען אותם לבד. |
| `archive/` | גרסאות ישנות. לא בשימוש. |

## כללים

כתובית חדשה הולכת ל `subs/`, ונרשמת ב `SRTMAP` בתוך `index.html` עם הקידומת `subs/`.
